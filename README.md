Banking App

This project is a modern online banking application designed to help users connect financial accounts, review balances, monitor transaction history, and organize spending activity from one responsive dashboard. Built with Next.js and Tailwind CSS, the application integrates the Plaid API for secure access to test banking data and uses Sentry for application monitoring. It demonstrates Jade's ability to build user-friendly financial applications, integrate third-party APIs, protect sensitive configuration, and monitor application reliability.
